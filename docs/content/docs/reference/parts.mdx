The bundled library ships connector families with cavity layouts, gauge
ranges, mating pairs, crimp tooling, and dated provenance. The families are
Molex Micro-Fit 3.0 and Mega-Fit, JST PH and XH, TE Deutsch DT, and AMASS
XT60.

Only the Micro-Fit 3.0 housings are currently marked `verified`. Everything
else is `inspired-by`, which means the shape is right but a limit a rule judges
against has not been checked against a datasheet. The `Verification` column
below says which is which, and `nerve provenance` names the ones a given report
depends on.

## Reach a part

Prefer the compact spec over memorizing MPNs:

```ts
import { part } from '@grayhaven/nerve-connectors'

const mcu = connector('MCU1', part('microfit-2x8')) // 43025-1600
const drop = connector('S1', part('dt-4s')) // Deutsch DT06-4S
```

Raw MPNs work too, case-insensitively, and common vendor spellings normalize.
Family objects are also exported directly:

```ts
import { MolexMicroFit } from '@grayhaven/nerve-connectors'

const j1 = connector('J1', MolexMicroFit['43025-0800'], { pins: { 1: 'VBAT_24V' } })
```

## Check what a part enables

Part data is what turns checks on. `nerve parts` reports both sides of that:

```bash
npx nerve parts ph-2
```

```text
mpn        PHR-2
specs      ph-2
family     PH
desc       JST PH housing, 2 circuits
pins       2
gender     receptacle
gauge      24AWG to 32AWG
current    2A
voltage    100V
mates with B2B-PH-K-S
verified   inspired-by
checks     6 active, 3 inactive
  inactive HK-CONN-013 — needs sealed
  inactive HK-CONN-014 — needs compatibleSeals
  inactive HK-CONN-015 — needs reservedPins
```

## Verification status

The `Verification` column below is a provenance claim, not a rating:

- **`verified`** — the load-bearing fields were checked against manufacturer
  data on a recorded date.
- **`inspired-by`** — the shape is right, but a limit a rule judges against
  has not been verified against a datasheet.

`nerve provenance` lists every `inspired-by` part a report currently depends
on. A clean report is only as good as those.

## Add your own

```bash
npx nerve parts scaffold MY-MPN-1234 --pins 6 --out ./parts
```

The scaffold includes every rule-relevant field, so nothing important is left
out by omission. For a library that lives elsewhere, register a provider. See the [SDK
reference](/docs/reference/sdk).
